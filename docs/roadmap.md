# Roadmap

Planned work lives outside this documentation set, in two files at the repository
root. [FEATURES.md](https://github.com/Rake-Pro/go-proxy-manager/blob/main/FEATURES.md)
is the roadmap: what has shipped, what is planned in P0-P3 tiers, and what is
explicitly out of scope.
[BACKLOG.md](https://github.com/Rake-Pro/go-proxy-manager/blob/main/BACKLOG.md)
tracks identified follow-ups on shipped features, checked off as they land.
Released changes are in
[CHANGELOG.md](https://github.com/Rake-Pro/go-proxy-manager/blob/main/CHANGELOG.md);
anything requiring an operator action on upgrade is repeated in
[Upgrading and rolling back](operations/upgrading.md).
